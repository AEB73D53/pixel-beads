🎨 AI 卡通 · API Key 获取教程

pixel-beads 的「AI 卡通化」调用商汤 SenseNova 图像生成模型，需要 API Key。约 3 分钟搞定。

1. 登录 SenseNova 开放平台

  • 打开 https://platform.sensenova.cn
  • 用手机号或账号注册 / 登录

2. 创建（或进入）一个应用

  1. 左侧菜单进入「控制台 / 应用管理」
  2. 点击「创建应用」，填个名字（比如 pixel-beads）即可
  3. 如果已有应用，点进去即可，无需新建

3. 开通图像生成模型

⚠️ 关键一步：模型默认可能未开通。必须在应用里添加图像模型，否则 API 会返回「未找到路由 / NOT_FOUND」。
  1. 在应用页面找到「模型开通 / 添加模型」
  2. 找到并启用 sensenova-u1.5-lite（图像创作模型，支持参考图 / 图生图）
  3. 确认已开通（有的模型需先充额度或完成实名认证）

4. 获取 API Key

  1. 进入「API Keys / 密钥管理」（URL 形如 /console/keys）
  2. 复制你的密钥，形如：
    sk-xxxxxxxxxxxxxxxxxxxxxxxx

5. 粘贴到 pixel-beads

  1. 打开 pixel-beads，右侧「⑤ 卡通化」面板下方的「AI 卡通」区
  2. 把 Key 粘贴到 Key 输入框，点「保存」
  3. 打开一张图片 → 点「AI 卡通化」即可
✅ 调用的接口：POST https://token.sensenova.cn/v1/images/edits，模型 sensenova-u1.5-lite。

常见问题

  • 提示「未找到路由 / NOT_FOUND」：该应用没开通图像模型。回第 3 步添加 sensenova-u1.5-lite。
  • 提示鉴权失败 / 401：Key 复制错了或已失效，重新复制。
  • 提示图片格式/尺寸不对：原图需 ≥256px、宽高比别太扁，程序会自动适配，极端图请换一张。
  • 提示超时：生成较慢或网络不稳，稍后再试。

你的 Key 只保存在本机设置文件中，不会上传、不会进代码仓库。请妥善保管，切勿公开。
