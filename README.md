# BeadCraft · 拼豆助手（Photo-to-Pattern）

**Turn any photo into a printable perler-bead pattern** — automatic background removal → pixel grid → palette quantization → numbered chart + shopping list. 100% local, no upload.

**把一张照片变成可以直接照着拼的拼豆图纸**：自动抠掉背景 → 转成像素格 → 映射到拼豆色卡 → 输出**图纸图 + 耗材清单**。纯本地离线运行，不上传任何图片。

**在线版**：仓库 `site/` 内含纯前端网页（官网 + 在线拼豆工具 + 灵感库），部署到 GitHub Pages 的方法见 [GITHUB_PAGES.md](GITHUB_PAGES.md)。

## 快速开始

### 方式一：直接运行 EXE（推荐给非开发用户）
打开 `dist\拼豆助手.exe`，双击即用。无需安装 Python。

### 方式二：源码运行（开发/自用）
```bash
pip install pillow numpy opencv-python openpyxl
python gui.py
```

## 使用步骤

1. **打开图片**：点击左上角「打开图片…」，选择照片（PNG/JPG/BMP/WebP）。上次用过的设置（色卡 / 颜色数 / 尺寸 / 最近图片）会自动记住。
2. **选择抠图方式**（右侧面板 ①）：
   - **自动去背景**：适合纯色背景（桌面、白墙）的照片，自动把背景变透明；
   - **手动框选**：在预览图上点两次框出主体区域（右键取消重选）；
   - **不抠图**：整张图都用来生成。
3. **设置网格大小**（②）：打开图片后会自动弹出「按图片推荐」窗口，按照片比例推荐小/中/大/超大几档等比例尺寸，点一下即套用；也可直接输入「宽×高」，或用预设按钮 29×29 / 45×45；勾选「按原图比例自动调整高」时，高度会按图片比例自动计算（宽度为准）。
4. **设置色卡与耗材**（③）：选择色卡（常用 40 色 / 进阶 78 色 / 你的自定义色卡），并设置「最多使用颜色数」——数字越小，用的豆子种类越少、越省事。点 **「色卡编辑」** 可管理自定义颜色与色卡（详见下文）。
5. **背景与空白格**（④）：勾选后，抠图留下的空白格会用白色豆填满（适合需要铺满底板的图案）；不勾选则留空、不耗豆。
5. **AI 卡通化（⑤，需联网 + API Key）**：先点**「🔑 获取 Key 教程」**填好商汤 SenseNova 的 Key，然后——
   - **选风格方向**：奶油 / 写实 / 像素 / 漫画 / 简洁 / 水彩，点一下即换，不用手打提示词；
   - **选生成方式**：**图生图**（把你的照片改风格，默认）或 **文生图**（凭空创作，视接口支持）；
   - **★ 拼豆友好化**（默认开启）：生成后自动**减少渐变、合并相近色、加粗轮廓**，并映射到你选的色卡——保证拼出来好看、豆子买得到；
   - **前后对比弹窗**：同时显示「AI 原始图」和「拼豆优化版」+ 色数对比（如 9216 色 → 5 色），让你选一张作为图纸底图，再点「生成图纸」。
6. 点 **「生 成 图 纸」**：右侧的**分段进度条**会逐步显示「网格化 → 颜色映射 → 渲染预览」三个阶段与整体进度百分比；完成后左侧预览区立即显示图纸，下方给出统计信息（尺寸 / 用色 / 总豆数）。
7. **查看与辅助**：
   - 工具栏 **「编号图 / 颜色图」** 切换预览（编号图尾部有图例对照）；
   - 支持**滚轮缩放**、**按住滚轮（中键）拖动平移**、按钮「＋／－ / 适应画布」；
   - **单色分布条**（生成后出现在画布下方）：点任意颜色，**颜色图与编号图都只高亮显示该色的格子**（编号图里其余编号淡显），方便一次性放完同色豆；再点同一色或「全部」恢复；
   - **⟷ 水平翻转 / ⟳ 垂直翻转**：镜像图纸（拼豆常需反着拼），生成后随时翻转；
   - **拼制进度**：生成后直接**点击格子**即可标记“已拼”（显示 ✗ 记号），状态条实时显示已拼格数/百分比；点 **「↺ 重置进度」** 清零。
7. **保存 / 导出（含预览确认）**：
   - **保存图纸(PNG)**：先弹出**完整图纸预览**（含小预览、大格子主图、色卡图例），确认后选路径保存；
   - **保存耗材清单**：先弹出**清单文本预览**（逐色列出名称 / 色值 / 所需颗数），可存为 txt，或点 **「另存为 Excel」** 导出 .xlsx（表格含色块示意，方便采购/记账）；
   - **导出 PDF**：一键生成**可打印 PDF**——图纸自动拆分为 A4 页 + 末页耗材清单。
8. **中 / English 切换**：顶栏右侧 **🌐** 按钮在**中文 / English** 间切换，整个界面（含弹窗、导出图纸图例、耗材清单）即时刷新为所选语言，选择会被记住，下次启动沿用。

## 拼豆灵感（找灵感 / 推荐备选）

点顶栏 **「拼豆灵感」** 打开面板，两页可用：

- **精选·本地灵感**：显示灵感库里的参考图（随包预置的在线采集图 + 你自己采集 / 导入的图）。网格缩略图 → 点选放大预览（标注来源）→ **「用作底图」** 一键载入主流程，调整尺寸 / 色卡后直接生成。
- **在线找灵感**：输入关键词（默认「拼豆图纸」）点「检索并下载」，从 **Bing 图片公开索引**限速采集（含小红书、堆糖、知乎等平台的公开拼豆图，个人参考用途），下载后自动切回精选页。也提供 **「在浏览器打开小红书/百度图片」** 按钮——登录平台自行挑选，右键保存后点「从本地导入图片」加入灵感库。

> 版权与规则：在线采集仅用于个人拼豆创作参考，小批量、限速；小红书 / 微信公众号有登录与风控，未做直连抓取。

## 色卡管理（导入真实品牌色号）

点右侧 **「色卡编辑」** 打开管理窗口：

- **自定义颜色**：为你的品牌豆（伊思 / MARD 等）新增「颜色名 + 十六进制色号」，可随时删除；
- **我的色卡**：新建 / 编辑 / 重命名 / 删除自己的色卡（勾选组成颜色，可搜索）；
- **导入 JSON**：支持两种格式
  - `colors` 列表 —— 引用已有颜色名；
  - `hexes` 映射 —— 颜色名对应真实色号（如品牌精确色号），导入即自动注册自定义颜色。
- 所有修改点 **「保存」** 后写入 `user_palettes.json`（源码版在项目目录，打包版在 exe 同级），下次启动自动加载。

## 技术说明

- 界面：现代拟态（Neumorphism）卡片风，深色主头 + 柔和卡片 + 分段式进度条；画布支持锚定滚轮缩放、滚轮按下拖动平移；
- 抠图：CIELAB 色彩空间的背景建模 + 边缘平滑，纯色背景效果最佳；
- AI 卡通化：商汤 SenseNova 图像模型（图生图/文生图）+ 本地**拼豆友好化**（`bead_friendly`：平滑 → K-Means 压色 → 映射色卡 → 加粗轮廓），保证生成图转图纸后依然好看、豆子买得到；
- 网格化：按格子区域求非透明像素的平均色，保留主体轮廓；
- 颜色映射：把每格平均色映射到色卡中最接近的颜色；当色卡颜色数超过「最多使用颜色数」时，先对主色做 K-Means 聚类控制耗材种类；
- 图纸：Pillow 渲染，包含小预览、格子主图与图例/清单；保存前均有预览确认弹窗；
- 导出：PNG 直接保存；PDF 由 Pillow 分页生成（A4 / 150dpi）；Excel 由 openpyxl 生成（按色块填充示意色）；
- 灵感：在线采集解析 Bing 图片公开索引直链，限速限量、来源写入 sources.json；灵感库随 exe 分发包内置的参考图 + 用户采集/导入的图。
- 双语：顶栏 🌐 切换中 / English，界面与导出文字经 `i18n.tr()` 翻译；色卡颜色名是算法数据，不随语言翻译。

## 已知限制

- 复杂背景（杂乱的室内场景）自动抠图效果有限，请改用「手动框选」；
- 内置色卡为泛品牌近似色，真实品牌色号请通过「色卡编辑 → 导入」自行录入；
- 在线灵感图为 Bing 索引的公开图片，版权归原作者，仅限个人拼豆参考，勿商用 / 转载。
